# 设计系统 · 课程知识平台

> 依据 **Claude Code 官方 `frontend-design` skill**（`~/.claude/skills/frontend-design/SKILL.md`）建立。
> **核心要求**：先定**明确的美学方向**并精确执行；**禁止**通用 AI 美学（Inter/Roboto/Arial/系统字体、紫渐变白底、可预测布局）。
> 版本 v1.0 ｜ 2026-10-15

---

## 1. 设计思考（先于代码）

| 维度 | 结论 |
|---|---|
| **Purpose** | 中国高校《数据库与数据仓库》课程的学生与教师。深层场景：**长时间盯着查一个语法、追一条引用、翻到原文第 1040 页** —— 这是**参考手册**性质的工具，不是营销页 |
| **Tone** | **「数据库内部 / 工业技术手册」** —— 冷峻、精密、纸感、有编号文化 |
| **Constraints** | Vue3 + Vite；中文为主；要支持暗色；图谱需渲染 1600+ 节点；**字体必须离线可用** |
| **Differentiation** | **知识点卡片长得像一条数据库记录，且每条都带"原文页码"作为视觉主角** —— 把「可核查性」这个产品差异**变成美学符号** |

### ⚠️ 现状诊断（为什么"不美观"）

当前 `src/style.css` 正是 skill 点名禁止的形态：

```css
--bg: #f5f6f8;                                        /* 通用浅灰 */
--panel: #ffffff;                                     /* 纯白 */
--accent: #2f5fd0;                                    /* 通用蓝 */
--sans: "Segoe UI", "Microsoft YaHei", system-ui;     /* ★ 系统字体 —— skill 明令禁止 */
```

**再加圆角卡片 + 13px 灰字 + 均匀留白** = 典型的"AI 生成感"。
问题不在细节，在**没有美学方向**。

## 2. 美学方向：「数据库内部 / 工业技术手册」

三条指导性隐喻，一切设计决策回到它们：

1. **纸与墨** —— 不是屏幕白，是**手册纸**。正文如印刷，长时间阅读不刺眼。
2. **编号与页码** —— 手册的一切都**可回溯**。页码、行号、证据号要有**视觉权重**，不是灰色小字。
3. **索引指针** —— 数据库用指针把记录连起来。**朱红**是我们唯一的强调色：它标记"这里可以跳"。

### ⚠️ 禁止清单（违反即打回）

| 禁止 | 替代 |
|---|---|
| ❌ `Inter` / `Roboto` / `Arial` / `system-ui` / `-apple-system` 作主字体 | ✅ **宋体做标题 + 等宽做元数据 + 黑体做正文**（见 §3） |
| ❌ 紫色渐变、白底 + 淡紫/淡蓝渐变 | ✅ 纸感纯色 + **单一朱红**强调 |
| ❌ 纯白 `#fff` 面板 + `#f5f6f8` 背底 | ✅ 纸白 `#fbf9f4` 系（见 §4） |
| ❌ 通用蓝 `#2f5fd0` 当唯一强调色 | ✅ 朱红 `#c0392b` 系 |
| ❌ 大圆角（≥12px）、柔和弥散阴影堆叠 | ✅ 小圆角（2–6px）+ **硬边线**为主、阴影克制 |
| ❌ 均匀分布的中间灰阶（每个元素都 13px 灰） | ✅ **强对比**：要么墨黑，要么明确弱化 |
| ❌ 均匀留白、可预测的三栏 | ✅ 网格线、编号、非对称边注 |

## 3. 字体（**离线可用**，不依赖 CDN）

```css
/* 标题 / 显示 —— 中文衬线：学术手册感，与"书"的隐喻一致 */
--font-display: "Noto Serif SC", "Source Han Serif SC", "Songti SC",
                "STSong", "SimSun", Georgia, serif;

/* 正文 —— 中文黑体（优先系统已装，避免打包 10MB CJK 字体） */
--font-body: "Noto Sans SC", "Source Han Sans SC", "PingFang SC",
             "Microsoft YaHei", "Segoe UI", sans-serif;

/* 元数据 / 标识符 / 页码 / SQL —— ★ 承担"技术感"的主力 */
--font-mono: "JetBrains Mono", "IBM Plex Mono", "Cascadia Mono",
             Consolas, "SFMono-Regular", monospace;
```

**要求**：
- **`JetBrains Mono` 用 `@fontsource/jetbrains-mono` 打包进项目**（纯拉丁子集，几十 KB，离线可用，不走 CDN）。
  → `pnpm add @fontsource/jetbrains-mono`，在 `main.ts` 里 `import '@fontsource/jetbrains-mono/400.css'`（+700）。
- **中文用系统衬线/黑体**（Windows 有 SimSun/宋体、Microsoft YaHei；macOS 有 Songti SC/PingFang）
  —— 这是**刻意的取舍**：不打包 10MB+ CJK 字体，但**绝不退回 `system-ui` 通用栈**。
- **字号阶梯**（比现在更大、对比更强）：

| 用途 | 字号 / 字重 | 字体 |
|---|---|---|
| 页面主标题 | 24–30px / 700 | display |
| 区块标题 | 16–18px / 700 | display |
| 卡片知识点名 | 15px / 700 | **mono**（标识符本体） |
| 正文 | 13.5–14px / 400，`line-height: 1.75` | body |
| 元数据（页码/边类型/ID） | **11px / 500，`letter-spacing: .04em`，大写字距** | mono |
| 代码 / SQL | 12.5px | mono |

## 4. 色彩（**单一强调色**，纸感）

### 亮色（默认）—— 手册纸

```css
--paper:        #f7f4ec;   /* 背底：暖白纸（不是 #f5f6f8 冷灰） */
--paper-2:      #efeade;   /* 次级纸：侧栏/条纹行 */
--panel:        #fdfcf8;   /* 卡片：纸白（不是 #fff） */
--rule:         #ddd5c4;   /* 网格线：纸上的淡墨线 */
--rule-strong:  #c4b9a2;   /* 强调分隔（表头下、区块界） */
--ink:          #1c1a16;   /* 墨黑正文 */
--ink-2:        #4a453c;   /* 次级正文 */
--muted:        #7d7566;   /* 弱化（必须真弱，别用中间灰凑） */
--accent:       #b8332a;   /* ★ 朱红 —— 唯一强调色（索引指针/可跳转/当前项） */
--accent-ink:   #8f251d;   /* 朱红深（hover / 文字） */
--accent-soft:  #f3e2de;   /* 朱红浅底（选中行、标记） */
--ok:           #2f6b4f;   /* 墨绿（成功，低饱和） */
--warn:         #9a6a1f;   /* 赭石（警告） */
--bad:          #b8332a;   /* 同 accent（错误语义复用朱红） */
```

### 暗色 —— 深墨 + 纸字

```css
--paper:        #14161a;   /* 不是纯黑，是墨蓝黑 */
--paper-2:      #1b1e24;
--panel:        #191c21;
--rule:         #2b3038;
--rule-strong:  #3a4149;
--ink:          #e8e4da;   /* 纸白字（不是纯白） */
--ink-2:        #b6b1a6;
--muted:        #7c776d;
--accent:       #e0564a;   /* 暗底上朱红提亮，保证对比度 ≥4.5:1 */
--accent-ink:   #f07a6e;
--accent-soft:  #33201d;
```

**规则**：
- **强调色只用于**：可跳转（引用/页码）、当前选中项、关键状态。**不要**用来装饰标题或铺大面积。
- **对比度**：正文与背底 ≥ **7:1**；元数据 ≥ **4.5:1**（现在是 13px 灰字，普遍不达标）。
- **不要**中间灰阶堆叠。层级靠**字号 + 字重 + 字体（衬线/等宽/黑体）**区分，其次才靠颜色。

## 5. 空间与形状

```css
--r-sm: 2px;    /* ★ 小圆角。禁止 ≥12px 的大圆角 */
--r-md: 4px;
--r-lg: 6px;
--hair: 1px;    /* 网格线统一 1px，颜色 --rule */
--shadow-1: 0 1px 0 var(--rule-strong);      /* ★ 用"硬边"代替弥散阴影 */
--shadow-2: 0 2px 8px rgba(28,26,22,.10);    /* 仅浮层（下拉/弹窗）用 */
```

**布局原则（skill 的「Spatial Composition」）**：
- **网格线代替分隔留白** —— 手册感来自"有线可依"。区块之间用 1px `--rule`，不要靠 24px 空白。
- **非对称**：左侧树栏窄（280px），右侧内容区**允许更宽**，并保留一条**右侧边注栏**（放页码/证据/引用，像手册的页边批注）。
- **打破均分**：卡片不用等宽三栏网格；用**单列 + 边注**的"论文版面"更贴合阅读场景。
- **密度**：这是参考工具，**允许高密度**（`--density: compact`），不要为了"呼吸感"牺牲信息量。

## 6. 动效（**克制但有一个高潮**）

skill 要求"one well-orchestrated page load with staggered reveals"。

| 场景 | 做法 |
|---|---|
| **页面进入** | 卡片**错峰淡入**（`animation-delay: calc(var(--i) * 30ms)`，`translateY(6px)→0`，180ms，`ease-out`） |
| **树节点展开** | 高度过渡 140ms + 子项错峰 20ms |
| **跳转到引用** | **朱红高亮闪烁 2 次**（`outline` 脉冲 700ms）—— 与 v1 的行为一致，但用 accent 色 |
| **hover** | 位移 ≤1px + 边线变 `--accent`。**不要**放大、不要阴影膨胀 |
| **图谱** | 力导向收敛后**淡入**边，节点按 degree 大小错峰出现 |
| **字幕跟随** | 当前行**左侧朱红竖条**滑动（`transform: translateY`，120ms） |

**禁止**：超过 300ms 的过渡、弹跳曲线（bounce）、无意义的循环动画、骨架屏之外的 loading 转圈。

## 7. 关键组件规格

### 7.1 知识点卡片（**差异化的主角**）

```
┌────────────────────────────────────────────────────────────┐
│ ▍log_filter_dragnet                    [log_filter]  p.1040 │  ← 名称用 mono；页码是**主角**
│                                                            │
│   一个可加载的错误日志过滤器组件，按用户自己写的规则决定       │
│   哪些错误写入日志                                          │
│                                                            │
│   用途 · 让 DBA 精确控制错误日志内容，避免日志被淹没          │
│                                                            │
│   ┌ EXAMPLE ─────────────────────────────────────────────┐ │  ← 小标签用 mono 大写 + 字距
│   │ INSTALL COMPONENT 'file://component_log_filter_dragnet';│
│   └───────────────────────────────────────────────────────┘ │
│                                                            │
│   ¶ 使用它会忽略 log_error_suppression_list                 │  ← 注意项用朱红竖条
│                                                            │
│   引用 ⟶ VARCHAR · ALTER TABLE · 还出现在 7.4.2            │  ← 引用用 accent 色
└────────────────────────────────────────────────────────────┘
```

- 左侧 **2px 朱红竖条**（`border-left`）标记卡片边界 —— 代替圆角+阴影
- **页码/证据**放**右上角**，`--font-mono`，可点击 → 跳原文。**这是视觉主角**，不要做成灰色小字
- 示例块：`--paper-2` 底 + 1px 边线 + 顶部 mono 小标签（`EXAMPLE`），**不用圆角气泡**
- 卡片**不留大圆角**（`--r-sm` 或 0），靠边线与竖条分隔

### 7.2 知识树（左侧栏）

- 节点行高 **26px**（紧凑），层级用**左缩进 + 竖线**（`border-left` 灰线）表达，**不要**用三角图标堆叠
- **页码右对齐**，mono，`--muted`
- **无内容的节点**：名称后跟 `–`（短横），`--muted`，与有内容的节点形成**明确对比**
- 当前节点：`background: --accent-soft` + 左 2px `--accent`

### 7.3 图谱

- 画布底色用 `--paper`（亮）/ `--paper`（暗），**不要**现在的 `#11151d` 纯深色 —— 要与整体纸感统一
- 节点：按 `layer` 着色（**低饱和**调色板），`degree` 决定半径
- 边：12 种 `etype` 用 12 色（**低饱和**），`flagged` 用**虚线**
- 选中节点的 1 跳邻居**高亮**，其余降到 25% 不透明度（"聚焦"语义）

### 7.4 视频页

- 播放器下方**字幕区**：当前行左朱红竖条，时间码 mono 右对齐
- 文稿分章：章节标题用 `--font-display`，时间码 mono
- 思维导图：**线条用 `--rule`，节点文字用 body**，不要彩色盒子

## 8. 实施要求（给实现者）

1. **只改样式与展示层**，不动数据契约、不改 API 调用、不改路由
2. **CSS 变量全部替换**（§4 是权威）；现有 `--sans/--bg/--panel/--accent` 等语义保留但取值换掉，
   **新增** `--font-display/--font-body/--paper/--rule/--accent-ink`
3. **换字体栈**（§3），并 `pnpm add @fontsource/jetbrains-mono` 打包等宽字体
4. **暗色模式必须同步改**（不能只改亮色）
5. **对比度自检**：正文 ≥7:1、元数据 ≥4.5:1（用工具量，不要凭感觉）
6. **headless Chrome 截图验证** —— 每个视图（Wiki/Graph/Video/Chat/Docs）亮暗各一张
7. **不引入 UI 组件库**（Element/Ant）—— 会立刻退回"通用 AI 观感"
8. 改完给出：**改动文件清单 + 截图 + 对比度实测数字**

### 验收

- [ ] 强调色唯一（朱红），无紫色渐变、无纯白面板
- [ ] 卡片有左侧朱红竖条 + 右上角可点击页码
- [ ] 亮/暗两套都改完
- [ ] 5 个视图截图各 1 张（亮暗），**肉眼可辨"手册感"**
